# Nou grau de Física UB · versió informativa

Web estàtica que explica, per a tot l’estudiantat, com s’organitza la proposta del nou grau de Física de la Universitat de Barcelona (23/09/2026): estructura per semestres, matèries troncals, laboratoris, mencions, optatives i canvi de menció. Disponible en català (per defecte) i castellà.

- `index.html`: tota la pàgina, autònoma (inclou React 18.3.1). Funciona també oberta directament des de l’ordinador.
- `.nojekyll`: indica a GitHub Pages que publiqui els fitxers tal com són.

## Publicar a GitHub Pages

1. Crea un repositori públic (per exemple, `nou-grau-fisica-ub-info`), o una carpeta nova dins d’un repositori existent.
2. Puja-hi el contingut d’aquesta carpeta.
3. A *Settings › Pages*, tria *Deploy from a branch*, branca `main` i carpeta `/ (root)`.

Resum informatiu d’una proposta provisional; no és informació oficial de la UB.
